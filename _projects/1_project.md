Woody is a full-stack iOS app for personalized Stanford dining and event recommendations.
The project integrates agent-based decision loops so recommendations can adapt to user context, preferences, and campus activity.

Core ideas:

- context-aware recommendation for daily Stanford life;
- LLM-assisted decision loops for ranking dining and event options;
- mobile-first user experience for fast campus use.
