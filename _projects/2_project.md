Redraw is a collaborative art platform built around generative image workflows.
It uses Stable Diffusion 3.5 with asynchronous FastAPI services to support responsive collaborative creation.

Core ideas:

- collaborative art generation;
- diffusion-model-backed image workflows;
- asynchronous backend services for interactive creation.
