This project explored quantitative factor modeling and stock prediction with a full machine learning pipeline.
The system combined feature selection, deep sequence modeling, hyperparameter optimization, and text-based signals.

Methods included:

- correlation filtering, Lasso, and LightGBM for feature selection;
- LSTM + Transformer sequence models;
- Optuna hyperparameter optimization;
- BERT-based text embeddings.
